# Aiko - Быстрый старт

Путь от чистой установки до завершённой задачи за несколько минут.

## 1. Запустите демон и откройте UI

```powershell
aiko serve     # в одном терминале
aiko ui        # в другом (открывает браузер и сопрягает его с демоном)
```

## 2. Зарегистрируйте проект

В UI нажмите **Добавить проект**, укажите путь к папке проекта и имя, выберите git policy.
Aiko создаст каталог `.aiko` и зарегистрирует проект.

Можно и из терминала:

```powershell
aiko init C:\path\to\your\project --name "My Project"
```

## 3. Подключите агента

Установите глобальную интеграцию агентов один раз (она добавляет MCP-запись Aiko, скиллы и память
во все найденные агенты), затем подключите агента к этому проекту:

```powershell
aiko agent install --project <projectId>
```

Затем перезапустите агента, чтобы он загрузил MCP-сервер проекта.

## 4. Создайте карточку

В агенте (внутри проекта):

```text
/aiko-init                # только если проект ещё не зарегистрирован
/aiko-create task Добавь страницу настроек   # укажите тип, затем что нужно
/aiko-create bug Не работает выпадающий список
```

Типы берутся из самого проекта: каждый workflow в **Настройках проекта - Workflow** и есть тип карточек,
поэтому тип, добавленный там (*Epic*, *Bug*), можно создавать сразу - `/aiko-create` читает контекст
проекта, а не перечисляет типы жёстко, и для каждого типа генерируется `/aiko-create-<тип>`.

Или простым языком: *"Создай задачу - добавить страницу настроек"*. Те же карточки создаются в
UI кнопкой **Карточка** на доске.

## 5. Ведите по этапам

Агент сначала читает контекст проекта, затем работает поэтапно:

```text
/aiko-next-stage   # перейти на следующий этап
/aiko-analyze      # анализ
/aiko-implement    # реализация
/aiko-review       # ревью
/aiko-complete     # готово
```

Перетаскивайте карточки между колонками на доске для того же эффекта. Когда нужны файлы вне
scope карточки, агент вызывает `aiko_request_scope_expansion` и ждёт вашего решения.

## 6. Завершите и сохраните знания

```text
/aiko-complete     # зафиксировать фактические файлы и артефакты
/aiko-memory       # сохранить долговременные решения и уроки
```

Коммиты подчиняются политике проекта (`deny` по умолчанию - коммитите вы; `ask` - агент
спрашивает; `allow` - агент коммитит). UI показывает доску, страницу проекта (статистика, скорость,
распределение), карточку (scope, критерии приёмки, дифф из git, обсуждение, запуски) и наборы workflow -
всё с live-обновлением по SSE.
